R.001 / Software engineering · Agentic systems · 2026

Rebuild Dossier: Mechanically-Enforced Specs for Agentic App Rebuilds, and What Model-Tier Failures Reveal

Rebuild Dossier is an open-source MCP server that extracts interface contracts and tests from an existing Express or Next.js application. It packages those materials for a fresh coding agent and adds hooks that enforce parts of the rebuild workflow. The tool produces a spec and evaluation materials; the agent performs the rebuild.

R.002 / Quantitative finance · Machine learning · 2026

When AUC Survives but Portfolios Do Not: Leakage, Accounting Errors, and Selection Instability in a Retail-Scale Machine-Learning Equity Study

An audit of a tree classifier ranking stocks by probability of beating a market benchmark, across 188 monthly cross-sectional decisions over a 200-stock U.S. equity universe. Correcting validation-label leakage and return-aggregation errors left test AUC nearly unchanged (0.553 → 0.551), but replaced 61.1% of the selected portfolio (mean Jaccard overlap 0.389) — aggregate accuracy survived while the actual decisions did not. A frozen 12-minus-1-month momentum rule outperformed the corrected model and a fixed ensemble once the ledger was fixed.

What the evaluation found

A passing suite can leave the wrong behavior intact.

In a sealed follow-up on one application, all 30 rebuild snapshots passed the 20 visible tests. A separate requirements check found substantial differences in authentication and response behavior. The check covered 77 database-independent requirements out of 132 written checks; it was author-written and used a coarse response-key comparison. The result identifies a concrete limit of the generated suite in that setting, not a general failure rate for coding agents.
