02 / What I build

Systems I have shipped in a live game

Server-owned game state

Each player has a server session that owns the current customer, the clue truth, the phase, and pending rewards. Player actions are checked against round state and position before anything changes.

Progression and economy

Rewards are staged during a round and only paid after a successful one. Ranks, contracts and gear unlock as rounds are completed, and a cosmetic game pass is wired in.

Seeded, consistent presentation

Deterministic seeds drive customer poses and the work schedule, so the same person looks the same across every view, and schedules avoid back-to-back repeats.

Camera, UI and audio

ViewportFrame evidence panels, a CCTV-style camera feed with replay, and a state-driven audio system with mixing buses and preloading.

Save-data integration

A validated data schema over the open-source ProfileStore library, with fail-closed loading and append-only capture syncing.

Automated test fixtures

Isolated Luau fixtures that simulate a full 20-round campaign and exercise the review screen for all 12 anomaly types, so game logic can be checked without playing it.
